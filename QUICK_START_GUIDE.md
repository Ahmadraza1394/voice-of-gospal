## Accessing the Admin Panel

### Step 1: Open the Admin Login Page
1. Open your web browser (Chrome, Firefox, Safari, or Edge)
2. Go to your website address and add `/admin/login` at the end
   - Example: `https://voice-of-gospel.vercel.app/admin/login`

### Step 2: Sign In
1. Enter your admin email address
2. Enter your admin password
3. Click the "Sign In" button

**Important:** Keep your login credentials secure and don't share them with anyone.

## Managing Blog Posts

### How to Create a New Blog Post

1. **From the Admin Dashboard:**
   - Click on "Blogs" in the menu
   - Click the "Create New Blog" button

2. **Fill in the Blog Information:**
   - **Title:** Enter a catchy title for your blog post
   - **Category:** Choose a category (Sermon, Testimony, News, etc.)
   - **Featured Image:** Enter the image path (ask your web developer if you need help)
   - **Content:** Write your blog post content
   - **Published:** Toggle this ON to make the blog visible to visitors

3. **Save Your Blog:**
   - Click "Create Blog" button
   - You'll see a success message when it's saved

### How to Edit an Existing Blog Post

1. Go to Admin Dashboard → Blogs
2. Find the blog post you want to edit
3. Click the "Edit" button next to it
4. Make your changes
5. Click "Update Blog" to save

### How to Delete a Blog Post

1. Go to Admin Dashboard → Blogs
2. Find the blog post you want to delete
3. Click the "Delete" button
4. Confirm that you want to delete it

**Warning:** Deleted blog posts cannot be recovered!

### Publishing vs. Unpublishing

- **Published (Toggle ON):** The blog post is visible to website visitors
- **Unpublished (Toggle OFF):** The blog post is hidden from visitors but saved in the system

This is useful if you want to prepare a blog post in advance and publish it later.

## Managing Events

### How to Add a New Event

1. **From the Admin Dashboard:**
   - Click on "Events" in the menu
   - Click the "Create New Event" button

2. **Fill in the Event Details:**
   - **Title:** Event name (e.g., "Easter Sunday Service")
   - **Date:** Click the calendar icon and select the event date
   - **Time:** Enter the time (e.g., "10:00 AM")
   - **Location:** Enter where the event will take place
   - **Description:** Provide details about the event
   - **Image:** (Optional) Enter the image path

3. **Save the Event:**
   - Click "Create Event" button
   - The event will now appear on your Events page

### How to Edit an Event

1. Go to Admin Dashboard → Events
2. Find the event you want to edit
3. Click the "Edit" button
4. Make your changes
5. Click "Update Event" to save

### How to Delete an Event

1. Go to Admin Dashboard → Events
2. Find the event you want to delete
3. Click the "Delete" button
4. Confirm deletion

**Tip:** Delete past events to keep your Events page current and relevant.

## Managing Livestream

### How to Set Up YouTube Livestream

1. **From the Admin Dashboard:**
   - Click on "Livestream" in the menu

2. **Enter Your YouTube URL:**
   
   **Option A - For a specific livestream video:**
   - Copy the YouTube video URL (e.g., `https://www.youtube.com/watch?v=abc123`)
   - Paste it in the "YouTube URL" field
   
   **Option B - For your channel's live page:**
   - Use your channel live URL (e.g., `https://www.youtube.com/@voiceofthegospeltabernacle/live`)
   - This will always show your current live stream

3. **Add Service Times (Optional):**
   - Click "Add Service Time"
   - Enter the day (e.g., "Sunday")
   - Enter the time (e.g., "10:00 AM")
   - Click "Add Service Time" again to add more times

4. **Save Your Settings:**
   - Click "Update Livestream"
   - Your livestream will now appear on the Watch page

### How to Update Livestream URL

Simply follow the same steps above and enter a new YouTube URL. The old one will be replaced.

## Getting Help

### If Something Isn't Working

1. **Try logging out and logging back in**
   - Sometimes this fixes temporary issues

2. **Clear your browser cache**
   - Press `Ctrl + Shift + Delete` (Windows) or `Cmd + Shift + Delete` (Mac)
   - Select "Cached images and files"
   - Click "Clear data"

3. **Try a different browser**
   - If it works in another browser, the issue is browser-specific

4. **Check your internet connection**
   - Make sure you have a stable internet connection

### If You Forgot Your Password

Contact your web developer to reset your admin password.

### If You Need to Make Changes Beyond the Admin Panel

For changes like:
- Updating page content
- Changing colors or design
- Adding new pages
- Modifying navigation menu

Contact your web developer with your request.

4. **Don't use public computers** to access the admin panel
5. **Change your password regularly** (every 3-6 months)

## Frequently Asked Questions

**Q: How often should I post new blogs?**  
A: Aim for at least 1-2 blog posts per month to keep your website active and engaging.

**Q: Can I schedule blog posts to publish later?**  
A: Currently, you need to manually publish posts. You can create them as "unpublished" and publish them when ready.

**Q: How many events can I add?**  
A: There's no limit! Add as many events as you need.

**Q: Can visitors see unpublished blog posts?**  
A: No, only published blog posts are visible to website visitors.

**Q: What image size should I use for blog posts?**  
A: Recommended size is 1200x630 pixels. Contact your web developer for help with images.

**Q: Can I add videos to blog posts?**  
A: Currently, blog posts support text and images. For videos, use the Watch page or contact your developer.

**Q: How do I know if someone submitted the contact form?**  
A: You'll receive an email at nhomicil@yahoo.com with their message.

**Q: Can I have multiple admin users?**  
A: Yes! Contact your web developer to create additional admin accounts.
